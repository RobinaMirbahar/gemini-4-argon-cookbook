1. Unifying 1M Input & 1M Output Tokens (Long-Decode Continuation Protocol)

Generating up to 1,000,000 output tokens in a single logical generation requires resilient connection handling. Gemini 4 Argon introduces the Long-Decode Continuation Protocol in the Gemini Interactions API v2.

When a generation slice reaches a per-turn boundary while the model still has more content to emit, interaction.status returns "incomplete" along with a cryptographic continuation_token. You simply pass that continuation_token into the next client.interactions.create(...) call to seamlessly resume decoding:

from google import genai

client = genai.Client()

def generate_up_to_1m_tokens(prompt: str) -> str:
    full_output: list[str] = []
    continuation_token: str | None = None

    while True:
        kwargs = {
            "model": "gemini-4-argon",
            "generation_config": {
                "thinking_level": "high",
                "thinking_summaries": "auto",
                "max_output_tokens": 1_000_000,
            },
        }
        if continuation_token is None:
            kwargs["input"] = prompt
        else:
            kwargs["continuation_token"] = continuation_token

        interaction = client.interactions.create(**kwargs)

        for item in interaction.outputs or []:
            if getattr(item, "type", None) == "text":
                full_output.append(item.text)

        if interaction.status == "incomplete" and getattr(interaction, "continuation_token", None):
            continuation_token = interaction.continuation_token
            continue
        break

    return "".join(full_output)

2. First-Class thought Steps & Cryptographic Signatures

With client.interactions.create, reasoning is no longer hidden in raw text blocks. Gemini 4 Argon emits structured thought outputs containing both a human-readable summary and a verifiable signature (thought_signature) so multi-turn agentic workflows can preserve exact reasoning state across turns:

stream = client.interactions.create(
    model="gemini-4-argon",
    input="Design a lock-free ring buffer in Rust and prove linearizability.",
    stream=True,
    generation_config={
        "thinking_level": "high",
        "thinking_summaries": "auto",
    },
)

for chunk in stream:
    if chunk.event_type == "content.delta":
        if chunk.delta.type == "thought_summary":
            print(f"[Thought] {chunk.delta.content.text}")
        elif chunk.delta.type == "thought_signature":
            print(f"[Signature] {chunk.delta.signature[:24]}...")
        elif chunk.delta.type == "text":
            print(chunk.delta.text, end="", flush=True)
